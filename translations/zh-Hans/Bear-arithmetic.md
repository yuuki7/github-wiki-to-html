## 数

不一定要用熊，也可以用狗。数表示的是有多少个，不考虑它们之间的差异。

```
🐶🐶🐶
```

### 顺序

数有顺序：$1 < 2 < 3$。

但是，🧸、🐶 和 🐻‍❄️ 中哪一个是“第一个”呢？动物本身没有固有的顺序。不过，我们可以定义一个顺序，例如按大小来定。

## 偶数和奇数

偶数可以分成两个相等的部分；奇数不行，会余下 1。

| 奇数 | 偶数 |
| --- | --- |
| 🧸 | 🧸🧸 |
| 🧸🧸<br>🧸 | 🧸🧸<br>🧸🧸 |
| 🧸🧸<br>🧸🧸<br>🧸 | 🧸🧸<br>🧸🧸<br>🧸🧸 |

### 定义

设 $n$ 为整数。我们说：

- 如果存在整数 $k$ 使得 $n = 2k$，则 $n$ 是**偶数**。
- 如果存在整数 $k$ 使得 $n = 2k + 1$，则 $n$ 是**奇数**。

### 奇数有中间的一个

三只熊有中间的一个，四只熊没有。但是，如果三只熊排成三角形，就不清楚哪一只是中间的了。至少可以说：如果奇数只熊排成一排，就有中间的一个。

## 质数

如果一个数可以重新排列成长方形，它就是合数；如果不行，它就是质数。[^1]但是，1 既不是质数，也不是合数。最前面的质数是 2、3、5、7 和 11。
