Wir können eine Zahl $n$ als eine Ansammlung von $n$ Bären darstellen.

```
🧸

🧸🧸

```

## Zahlen

Man muss keine Bären verwenden; man kann auch Hunde nehmen. Eine Zahl gibt an, wie viele es sind, wobei die Unterschiede ignoriert werden.

```
🐶🐶🐶
```

### Ordnung

Zahlen haben eine Ordnung: $1 < 2 < 3$.

Aber welcher ist der „erste“: 🧸, 🐶 oder 🐻‍❄️? Tiere haben keine ihnen innewohnende Ordnung. Wir können jedoch eine Ordnung definieren, zum Beispiel nach Größe.

## Gerade und ungerade Zahlen

Eine gerade Zahl kann in zwei gleiche Teile geteilt werden; eine ungerade Zahl kann das nicht, es bleibt ein Rest von 1.

| Ungerade | Gerade |
| --- | --- |
| 🧸 | 🧸🧸 |
| 🧸🧸<br>🧸 | 🧸🧸<br>🧸🧸 |
| 🧸🧸<br>🧸🧸<br>🧸 | 🧸🧸<br>🧸🧸<br>🧸🧸 |

### Definition

Sei $n$ eine ganze Zahl. Wir sagen:

- $n$ ist **gerade**, wenn es eine ganze Zahl $k$ gibt, sodass $n = 2k$.
- $n$ ist **ungerade**, wenn es eine ganze Zahl $k$ gibt, sodass $n = 2k + 1$.

### Ungerade Zahlen haben eine Mitte

Drei Bären haben eine Mitte; vier haben keine. Aber wenn drei Bären ein Dreieck bilden, ist nicht klar, welcher die Mitte ist. Wir können zumindest sagen, dass es eine Mitte gibt, wenn eine ungerade Anzahl von Bären in einer Reihe aufgereiht ist.

## Primzahlen

Eine Zahl ist zusammengesetzt, wenn sie zu einem Rechteck umgeordnet werden kann; wenn nicht, ist sie prim.[^1] Die 1 ist jedoch weder prim noch zusammengesetzt. Die ersten Primzahlen sind 2, 3, 5, 7 und 11.
