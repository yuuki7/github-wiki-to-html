title: 11の次の素数は1111111111111111111
---

温泉のサウナでこんなことを考えた。

111は素数だろうか？

いや、3で割り切れる。

では1111は？

これは素数に見える。3でも5でも7でも割り切れない。しかし違う。因数分解ができる。$1111 = 11 \cdot 101$。

では11111は？そこで私はのぼせてしまった。

後になって、言葉の回文に興味を持ったことから、数学における文字列としての数を研究するようになった。

| 例 | 名前 | 素数になる条件 | OEIS | 正規表現 |
|------------------|--------------------|----------------------------|---------|----------|
| 11, 111, 1111    | レプユニット $R_n$      | $n$ が素数               | A002275 | `1+`     |
| 111, 222, 3333   | レプディジット           | レプユニット[^1]                | A010785 | `(.)\1*` |
| 123, 234, 5678   |                    |                            | A138141 |          |
| 121, 1221, 12321 | 回文数 | 長さが奇数[^2]          | A002113 |          |
| 101, 1001, 10001 |                    | $10^{2^n} + 1$ の形 | A000533 | `10*1`   |

## レプユニット

$11...1$ という形の数は<dfn>レプユニット</dfn>と呼ばれ、$R_n$ と書く。ここで $n$ は1の個数である。

$n$ が合成数なら、$R_n$ は $R_k$ で割り切れる。ここで $k$ は $n$ の約数である。例えば、$R_9 = 111,111,111$ は $R_3 = 111$ で割り切れる。

したがって、$R_n$ が素数なのは $n$ が素数のときに限る。

$R_2 = 11$ は素数だが、$R_3$ も $R_5$ も素数ではない。次の素数は $R_{19}$ と $R_{23}$ で、その次は $R_{317}$ である。

## レプディジット

111、222、3333のような数は<dfn>レプディジット</dfn>と呼ばれる。すべてのレプユニットはレプディジットである。

レプディジットは素数ではない（レプユニット素数と1桁の素数を除く）。レプユニットで割り切れるからである。例えば $777 = 7 \cdot 111$。
