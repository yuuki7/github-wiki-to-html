数 $n$ は、$n$ 匹のクマの集まりとして表すことができる。

```
🧸

🧸🧸

🧸🧸🧸
```

## 数

クマを使わなくてもよい。犬を使ってもよい。数とは、違いを無視して、いくつあるかを表すものである。

```
🐶🐶🐶
```

### 順序

数には順序がある：$1 < 2 < 3$。

しかし、🧸、🐶、🐻‍❄️のうち、どれが「最初」だろうか。動物には生まれつきの順序はない。ただし、たとえば大きさによって順序を定義することはできる。

## 偶数と奇数

偶数は2つの等しい部分に分けることができる。奇数はできず、1が余る。

| 奇数 | 偶数 |
| --- | --- |
| 🧸 | 🧸🧸 |
| 🧸🧸<br>🧸 | 🧸🧸<br>🧸🧸 |
| 🧸🧸<br>🧸🧸<br>🧸 | 🧸🧸<br>🧸🧸<br>🧸🧸 |

### 定義

$n$ を整数とする。このとき、

- $n$ が**偶数**であるとは、$n = 2k$ となる整数 $k$ が存在することである。
- $n$ が**奇数**であるとは、$n = 2k + 1$ となる整数 $k$ が存在することである。

### 奇数には真ん中がある

3匹のクマには真ん中があるが、4匹にはない。ただし、3匹のクマが三角形を作ると、どれが真ん中かははっきりしない。少なくとも、奇数匹のクマが一列に並べば、真ん中があるとは言える。

## 素数
