我們可以把一個數 $n$ 表示為 $n$ 隻熊的集合。

```
🧸

🧸🧸

🧸🧸🧸
```

## 數

不一定要用熊，也可以用狗。數表示的是有多少個，不考慮它們之間的差異。

```
🐶🐶🐶
```

### 順序

數有順序：$1 < 2 < 3$。

但是，🧸、🐶 和 🐻‍❄️ 中哪一個是「第一個」呢？動物本身沒有固有的順序。不過，我們可以定義一個順序，例如按大小來定。

## 偶數和奇數

偶數可以分成兩個相等的部分；奇數不行，會餘下 1。

| 奇數 | 偶數 |
| --- | --- |
| 🧸 | 🧸🧸 |
| 🧸🧸<br>🧸 | 🧸🧸<br>🧸🧸 |
| 🧸🧸<br>🧸🧸<br>🧸 | 🧸🧸<br>🧸🧸<br>🧸🧸 |

### 定義

設 $n$ 為整數。我們說：

- 如果存在整數 $k$ 使得 $n = 2k$，則 $n$ 是**偶數**。
- 如果存在整數 $k$ 使得 $n = 2k + 1$，則 $n$ 是**奇數**。

### 奇數有中間的一個

三隻熊有中間的一個，四隻熊沒有。但是，如果三隻熊排成三角形，就不清楚哪一隻是中間的了。至少可以說：如果奇數隻熊排成一排，就有中間的一個。

## 質數

如果一個數可以重新排列成長方形，它就是合數；如果不行，它就是質數。[^1]但是，1 既不是質數，也不是合數。最前面的質數是 2、3、5、7 和 11。
