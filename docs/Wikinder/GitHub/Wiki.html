Overview

Represents the Wikinder GitHub Wiki.

The wiki repository contains .md files; this class enumerates them, rewrites wiki-specific syntax, and produces YAML front matter with metadata for downstream consumers.

GitHub Wiki is flat — pages are addressed by name only — so subdirectory blobs are unsupported and ignored entirely.

Parameters:

  • path (String | Pathname) —

    path to the wiki repository.

  • options (Hash) (defaults to: {}) —

    Options for the build. Each key is documented below.

Options Hash (options):

  • :ungenerated_pages (Set[String]) —

    Pages the build never generates as articles. The default is the set the conversion CLI passes — the site parts and repository files that are not articles — so Home and _Footer are not emitted as ordinary articles. Pass a subset (such as Set) to opt out of each.

  • :unlisted_pages (Set[String]) —

    Pages kept out of the home page's list of articles.

  • :ignore_meta (Boolean) —

    Ignore committed META.md and derive authorship metadata from git history instead. Used for testing.

  • :prev_head (String, nil) —

    SHA of the commit this repo was last read at. Used for incremental META.md sync.

  • :site_language (String, nil) —

    The site's language, stamped onto special pages, whose originals belong to it. Site metadata belongs to the caller (the conversion CLI maintains it); the module never reads a site file and never detects a language for site parts.

  • :supported_languages (Array[String]) —

    The languages the site offers. Non-empty, the list declares the site's language set: the site language must belong to it, every page must exist in every language in it, and a translation directory naming any other language fails the build. Original pages may be written in any language: a page's language comes from its META row or from detection, and detection is a heuristic taken as it comes, never a ground truth to fail a build on. Empty, no set is declared: every language found is accepted, and a link to a page with no version in the reader's language points at the original.

  • :translations_dir (String, Pathname, nil) —

    Directory holding translated pages as data, one subdirectory per language (translations//.md). The files are inputs produced elsewhere — translation is not this module's business — and their front matter's only key read is title (the translated title).

def initialize(path, options = {})
  @path = Pathname(path.to_s).expand_path
  @repo = Rugged::Repository.new(@path.to_s)
  @head = @repo.head.target_id
  @history = History.new(@repo, @head)
  head_commit = @history.head_commit
  raise Error, 'HEAD does not name a commit' unless head_commit

  # Capture the tree once so walking / lookup during build does not
  # change mid-build (the wiki could otherwise move under a build).
  @tree = head_commit.tree
  @ungenerated_pages = Array(
    options.fetch(:ungenerated_pages) { Set['Home', 'README', 'LICENSE', 'META', '_Footer'] }
  ).to_set.freeze
  @unlisted_pages = Array(options[:unlisted_pages] || []).to_set.freeze
  @ignore_meta = options[:ignore_meta] == true
  prev_head = options[:prev_head]
  @prev_head = prev_head.is_a?(String) ? prev_head : nil
  supported = options[:supported_languages] || []
  site_language = options[:site_language]
  # A supplied site language must name a language: dropping a
  # malformed value would stamp the special pages with no
  # language and let a caller error build successfully.
  # Omitting the option stays valid; the special pages then
  # carry no language, as the option documentation states.
  @site_language = if site_language.is_a?(String)
                     normalized = Language.normalize(site_language, supported:)
                     if normalized.nil?
                       raise Error, "site_language #{site_language.inspect} does not name a language"
                     end

                     normalized
                   end
  # The same rule applies to each supported language the
  # caller named: a value that names no language fails here
  # instead of being dropped from the list silently.
  supported_list = supported.map do |code|
    normalized = Language.normalize(code, supported:)
    raise Error, "supported_languages entry #{code.inspect} does not name a language" if normalized.nil?

    normalized
  end
  @supported_languages = supported_list.uniq.freeze
  # When a language set is declared, the site language must
  # belong to it: the original special pages are part of the
  # set's matrix like any other page.
  site_language_value = @site_language
  if site_language_value && !@supported_languages.empty? &&
     !@supported_languages.include?(site_language_value)
    raise Error, "site_language #{site_language_value.inspect} is not a supported language"
  end

  translations_dir = options[:translations_dir]
  @translations_dir = translations_dir ? Pathname(translations_dir.to_s).expand_path.to_s : nil
end

#build(target_dir) ⇒ Object

Builds the entire output tree, writing Markdown files with YAML front matter.

Outputs are computed in memory first and written only when every one succeeded, each via a same-directory temporary file renamed into place: a crash can mix old and new files, but never tear an individual file. Files the new build no longer produces are then removed; unrelated files stay untouched. : (String) -> void

def build(target_dir)
  outputs = compute_outputs
  verify_confined!(target_dir, outputs)

  FileUtils.mkdir_p(target_dir)
  outputs.each do |relative, content|
    destination = File.join(target_dir, relative)
    FileUtils.mkdir_p(File.dirname(destination))
    temp = "#{destination}.tmp.#{Process.pid}"
    begin
      File.binwrite(temp, content)
      File.rename(temp, destination)
    ensure
      FileUtils.rm_f(temp)
    end
  end

  cleanup_stale_files(target_dir, outputs)
  meta_path = @meta_path
  meta_rows = @meta_rows
  Meta.write(meta_path, meta_rows) if meta_path && meta_rows
end
