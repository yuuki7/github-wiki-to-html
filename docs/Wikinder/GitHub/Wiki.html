Overview

Represents the Wikinder GitHub Wiki.

The wiki repository contains .md files; this class enumerates them, rewrites wiki-specific syntax, and produces YAML front matter with metadata for downstream consumers.

GitHub Wiki is flat: it has no notion of nested page directories, and pages are addressed by name only. Subdirectory blobs are therefore silently unsupported — they are ignored entirely.

  • options (Hash) (defaults to: {}) —

    Options for the build. Each key is documented below.

Options Hash (options):

  • :ungenerated_pages (Set[String]) —

    Pages the build never generates as articles. The default is the same set the conversion CLI passes — the site parts and repository files that are not articles — so Home and _Footer are not emitted as ordinary articles by default. Pass Set (or any subset) explicitly to opt out of each.

  • :unlisted_pages (Set[String]) —

    Pages kept out of the home page's list of articles.

  • :ignore_meta (Boolean) —

    Ignore committed META.md and derive authorship metadata from git history instead. Used for testing.

  • :prev_head (String, nil) —

    SHA of the commit this repo was last read at. Used for incremental META.md sync.

  • :site_language (String, nil) —

    The site's language, stamped onto special pages. Site metadata belongs to the caller (the conversion CLI maintains it); the module never reads a site file itself and never detects a language for site parts. It is also the language the original special pages belong to: every output is written under a language directory named by the page's own language.

  • :supported_languages (Array[String]) —

    The languages the site offers translations in. A translation directory naming any other language fails the build. When empty, every language found under the translations directory is accepted.

  • :translations_dir (String, Pathname, nil) —

    Directory holding translated pages as data, one subdirectory per language (translations//.md). Translation itself is not this module's business; the files are inputs, produced elsewhere, and may carry a YAML front matter whose only key the converter reads is title (the translated title).

def initialize(path, options = {})
  @path = Pathname(path.to_s).expand_path
  @repo = Rugged::Repository.new(@path.to_s)
  @head = @repo.head.target_id
  @history = History.new(@repo, @head)
  head_commit = @history.head_commit
  raise Error, 'HEAD does not name a commit' unless head_commit

  # Capture the tree once so walking / lookup during build does not
  # change mid-build (the wiki could otherwise move under a build).
  @tree = head_commit.tree
  @ungenerated_pages = Array(
    options.fetch(:ungenerated_pages) { Set['Home', 'README', 'LICENSE', 'META', '_Footer'] }
  ).to_set.freeze
  @unlisted_pages = Array(options[:unlisted_pages] || []).to_set.freeze
  @ignore_meta = options[:ignore_meta] == true
  prev_head = options[:prev_head]
  @prev_head = prev_head.is_a?(String) ? prev_head : nil
  supported = options[:supported_languages] || []
  site_language = options[:site_language]
  @site_language = site_language.is_a?(String) ? Language.normalize(site_language, supported: supported) : nil
  supported_list = supported.filter_map { |code| Language.normalize(code, supported: supported) }
  @supported_languages = supported_list.uniq.freeze
  translations_dir = options[:translations_dir]
  @translations_dir = translations_dir ? Pathname(translations_dir.to_s).expand_path.to_s : nil
end

#build(target_dir) ⇒ Object

Builds the entire output tree, writing Markdown files with YAML front matter.

All outputs are computed in memory first; only when computation of every page (or asset) succeeded are files written, each via a same-directory temporary file atomically renamed into place. A crash can therefore leave previous-generation and new files mixed, but never a torn individual file. After the write, files the new build no longer produces are removed (keeping anything unrelated to the build untouched). : (String) -> void

def build(target_dir)
  outputs = compute_outputs
  verify_confined!(target_dir, outputs)

  FileUtils.mkdir_p(target_dir)
  outputs.each do |relative, content|
    destination = File.join(target_dir, relative)
    FileUtils.mkdir_p(File.dirname(destination))
    temp = "#{destination}.tmp.#{Process.pid}"
    begin
      File.binwrite(temp, content)
      File.rename(temp, destination)
    ensure
      FileUtils.rm_f(temp)
    end
  end

  cleanup_stale_files(target_dir, outputs)
  meta_path = @meta_path
  meta_rows = @meta_rows
  Meta.write(meta_path, meta_rows) if meta_path && meta_rows
end
