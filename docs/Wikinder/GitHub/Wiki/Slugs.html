Overview

Consistent title ↔ slug conversion shared across the suite, mirroring gollum's handling of page files: spaces become hyphens, everything else passes through unchanged. The transform is lossy by design — a literal hyphen in a title is indistinguishable from the space→hyphen mapping, so title_for collapses both to spaces and no round-trip is assumed.

def self.safe?(slug)
  return false if slug.empty?
  return false if ['.', '..'].include?(slug)
  return false if slug.include?('/') || slug.include?('\\')
  return false if slug.start_with?('.') # dotfiles are never wiki pages
  # Filesystems cap the length of any single path component
  # (typically at 255 bytes). The .md extension consumes at most
  # 3 bytes, leaving 252 for the slug itself.
  return false if slug.bytesize > 252

  true
end
