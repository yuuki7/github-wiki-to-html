Overview

Converts the GitHub Wiki Markdown dialect to standard GFM Markdown.

Wikilinks use the double-bracket syntax: [[Page]], [[Page|Display]], images either use ![[image.png]] or reference a file by its image extension: [[image.png]] is taken to be an image.

Wiki links become standard Markdown links, except when they appear in raw HTML blocks, where the Markdown pipeline would not process them. All raw HTML blocks of a page are parsed together as a single HTML5 stream (Nokogiri), because constructs such as

routinely span several blocks separated by blank lines — parsing each block in isolation would auto-close elements that a later block closes and drop their closing tags. Wikilinks in text nodes are rewritten as raw HTML anchors; everything else is reserialized by the parser, which normalizes the markup (supplying an implied

, for example) rather than preserving the source bytes.

def self.build_elements(document, match, link_index)
  inner = match[1].to_s.strip
  if toc_literal?(inner)
    [Nokogiri::XML::Text.new(match[0].to_s, document)]
  elsif image_target?(inner)
    [build_image(document, inner, link_index)]
  elsif match[0].to_s.start_with?('!')
    [Nokogiri::XML::Text.new('!', document), build_anchor(document, inner, link_index)]
  else
    [build_anchor(document, inner, link_index)]
  end
end

def self.canonical_file_name(link_index, target)
  return target if link_index.nil?
  return target if target =~ %r{\A[a-z][a-z0-9+.-]*://}i

def self.range_for(offsets, source_position)
  start_line = source_position[:start_line]
  end_line = source_position[:end_line]
  # Commonmarker's +end_column+ is the 1-based column of the *last*
  # byte; an inclusive start column therefore maps to +column - 1+,
  # while the exclusive span end maps to +column+ exactly.
  first = offsets[start_line - 1] + source_position[:start_column] - 1
  last = offsets[end_line - 1] + source_position[:end_column]
  first...last
end

.resolve_link_target(target, link_index) ⇒ Object

When the caller supplies the wiki's link index, a target that names an existing page is canonicalized to that page's own spelling — GitHub Wiki resolves internal links leniently (spaces/hyphens folded, case-insensitive), so the written form need not match the file name. A target that matches nothing is rendered as a regular link in its written form: marking missing pages (Gollum's "absent" class in HTML output) has no place in Markdown output and belongs, if anywhere, to the site layer.

The piped form never special-cases a leading '#': in gollum's one fixed rule the first thing is the display text, so [[#math|Math]] renders #math. Anchor handling applies only to the single-part form ([[#anchor]] -> anchor). Handles [[File.md#anchor]] explicitly: the anchor fragment must survive intact while only the page path component loses .md. A leading '#' is an in-page anchor and passes through unchanged. The path is percent-encoded for URL-unsafe ASCII characters (e.g. "a?b" becomes "a%3Fb") but left as-is for non-ASCII, so links remain human-readable for UTF-8 slugs. : (String, Hash[Symbol, Hash[String, String]]?) -> String

def self.resolve_link_target(target, link_index)
  return target if target =~ %r{\A[a-z][a-z0-9+.-]*://}i
  return target if target.start_with?('/')
  return target if target.start_with?('#')

  fragment = target.split('#', 2)
  path = fragment[0] || ''
  anchor = fragment[1]
  name = path.end_with?('.md') ? path.sub(/\.md\z/, '') : path
  canonical = link_index && index_lookup(link_index[:pages], name)
  slug = canonical || Slugs.for_title(name)
  resolved = "/#{escape_url_path(slug)}"
  anchor ? "#{resolved}##{anchor}" : resolved
end

def self.rewrite(source, segments, link_index)
  out = +''
  position = 0
  segments.each do |range, content|
    out << rewrite_fragment(source.byteslice(position...range.begin) || '', link_index)
    out << content
    position = range.end
  end
  out << rewrite_fragment(source.byteslice(position..) || '', link_index)
  out
end

def self.rewrite_fragment(text, link_index)
  text.gsub(WIKILINK_PATTERN) do
    match = Regexp.last_match
    raise 'gsub block without match data' if match.nil?

    inner = match[1].to_s.strip
    if toc_literal?(inner)
      match[0].to_s
    elsif image_target?(inner)
      render_image(inner, link_index)
    elsif match[0].to_s.start_with?('!')
      # The output is itself Markdown, so a bare '!' in front of
      # the link would be re-parsed downstream as an image. The
      # escape keeps it the literal text GitHub renders.
      "\\!#{render_markdown_anchor(inner, link_index)}"
    else
      render_markdown_anchor(inner, link_index)
    end
  end
end

.rewrite_html_stream(blocks, link_index) ⇒ Object

Rewrites wikilinks in a page's raw HTML blocks. The blocks are joined with unique comment markers and parsed as one HTML5 stream, so an element opened in one block can be closed in a later one; after rewriting, the stream is split at the markers again. Content the parser moved across a marker (an unclosed element before the first block, auto-closures after the last) is folded into the nearest block. If a marker does not survive the round trip — it can be swallowed as raw text, e.g. by a
