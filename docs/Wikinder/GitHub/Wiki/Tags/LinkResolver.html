Overview

Resolves the wikilinks of one page render against the wiki's link index and the routes of the language being rendered. Both are fixed for a whole page, so the pipeline carries one resolver instead of threading the pair through every step; only what varies from link to link is passed along.

def build_elements(document, match)
  inner = match[1].to_s.strip
  if Tags.toc_literal?(inner)
    [Nokogiri::XML::Text.new(match[0].to_s, document)]
  elsif Tags.image_target?(inner)
    [build_image(document, inner)]
  elsif match[0].to_s.start_with?('!')
    [Nokogiri::XML::Text.new('!', document), build_anchor(document, inner)]
  else
    [build_anchor(document, inner)]
  end
end

def build_image(document, inner)
  target, alt = Tags.image_parts(inner)
  target = canonical_file_name(target)
  element = document.create_element('img')
  element['src'] = target
  element['alt'] = alt.to_s.empty? ? File.basename(target, '.*') : alt
  element
end

def canonical_file_name(target)
  link_index = @link_index
  return target if link_index.nil?
  return target if target =~ %r{\A[a-z][a-z0-9+.-]*://}i
  return target if target.start_with?('/')

  Tags.index_lookup(link_index[:files], target) || target
end

def render_image(ref)
  target, alt = Tags.image_parts(ref)
  target = canonical_file_name(target)
  alt = File.basename(target, '.*') if alt.to_s.empty?
  "![#{Tags.escape_markdown_text(alt)}](#{Tags.link_destination(target)})"
end

#resolve_link_target(target) ⇒ Object

Canonicalizes a target that names an existing page to that page's own spelling, when the caller supplies the link index: GitHub Wiki resolves internal links leniently (spaces and hyphens folded, case-insensitive), so the written form need not match the file name. A target matching nothing is rendered as a regular link as written: marking missing pages (Gollum's "absent" class) has no place in Markdown output and belongs, if anywhere, to the site layer.

The piped form never special-cases a leading '#': the first part is the display text, so [[#math|Math]] renders as #math. Anchor handling applies only to the single-part form ([[#anchor]] becomes anchor); in [[File.md#anchor]] only the page part loses its .md.

With routes, the link takes the prefix routes give for the target's slug (see Wiki#routes_by_language); without routes, the historical root-relative form is kept. : (String) -> String

def resolve_link_target(target)
  return target if target =~ %r{\A[a-z][a-z0-9+.-]*://}i
  return target if target.start_with?('/')
  return target if target.start_with?('#')

  link_index = @link_index
  routes = @routes
  path, anchor = target.split('#', 2)
  path ||= ''
  name = path.end_with?('.md') ? path.sub(/\.md\z/, '') : path
  canonical = link_index && Tags.index_lookup(link_index[:pages], name)
  slug = canonical || Slugs.for_title(name)
  prefix = routes && (routes[slug] || (canonical && routes[canonical]))
  resolved = prefix ? "#{prefix}/#{Tags.escape_url_path(slug)}" : "/#{Tags.escape_url_path(slug)}"
  anchor ? "#{resolved}##{anchor}" : resolved
end

def split_ref(ref)
  parts = Tags.pipe_parts(ref)
  if parts.size >= 2
    text = parts[0].to_s
    target = parts[1].to_s
    [resolve_link_target(target), text]
  else
    single = parts[0].to_s
    if single.start_with?('#')
      [single, single.delete_prefix('#')]
    else
      [resolve_link_target(single), single]
    end
  end
end
