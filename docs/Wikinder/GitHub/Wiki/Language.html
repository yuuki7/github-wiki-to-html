Overview

Detects and normalizes the language code of a page.

Chinese is normalized to 'zh' (Simplified) or 'zh-hant' (Traditional): the site treats the two scripts as separate languages, and plain 'zh' names the default, Simplified. The script is decided by counting characters that exist in only one of the two scripts; no such character means Simplified, the larger readership.

def self.call(text, supported: [])
  return 'en' if text.nil? || text.strip.empty?

  code = WhatLanguage.language_iso(text)
  normalize(code&.to_s, text, supported:) || 'en'
end

def self.chinese_variant(code, text)
  return 'zh-hant' if %w[zh-tw zh-hk zh-mo zh-hant].include?(code)
  return 'zh' if %w[zh-cn zh-sg zh-my zh-hans].include?(code)
  return 'zh' if text.nil? || text.empty?

  simplified = text.count(SIMPLIFIED_ONLY)
  traditional = text.count(TRADITIONAL_ONLY)
  traditional > simplified ? 'zh-hant' : 'zh'
end

.normalize(code, text = nil, supported: []) ⇒ Object

Normalizes a language code to the form the site uses as a directory name. Chinese codes resolve to 'zh' or 'zh-hant' (the script detected from text when available); region variants of the supported languages collapse to the plain code. The caller names the supported languages — this module keeps no list of its own, so site.json stays the single source. Unknown codes pass through in lower case, the form URLs compare and carry language tags in. : (String?, ?String?, ?supported: Array) -> String?

def self.normalize(code, text = nil, supported: [])
  return nil if code.nil? || code.empty?

  downcased = code.downcase
  return chinese_variant(downcased, text) if downcased == 'zh' || downcased.start_with?('zh-')

  base = downcased.split('-').first.to_s
  supported.include?(base) ? base : downcased
end
